# ResiboReport.AI
Resibo Report is a prototype web-app that analyzes Gcash receipts, store them digitally in a secure database, and create reports (via a separate Dashboard). A better alternative than writing them by hand on paper, which has its own set of concerns (loss of record, overstacking of records, data integrity &amp; consistency, etc.)

Click this link to use the prototype: https://resibo-report-ai.vercel.app/
